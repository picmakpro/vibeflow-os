- Retard : « en retard de N commit(s) sur <base>, dernier fetch il y a X » (X par `age()` de `ds.ts`, « aucun fetch
  connu » si `fetchAgeS` est `null`) ; segment « · origin/<base> local : en retard de M » si `origin` > 0 ; rien si les
  deux valent 0 ou `null`.
- Worktree : « <label> · <branche> · phase <n> <nom> (<libellé d'avancement>) » ou « … · aucune phase en cours ».
- Mission courante : celle de `avancement.mission` de la phase active de l'arbre courant ; « mission <nom> · <libellé> ».
- Erreurs du socle : « node introuvable dans le PATH », « émetteur sans réponse (délai dépassé) », « émetteur en échec
  (code N) », « sortie de l'émetteur tronquée », « sortie de l'émetteur illisible », « schéma inattendu : <valeur bornée> » ;
  « verrous illisibles » quand `verrous.etat` ≠ `lue`.
