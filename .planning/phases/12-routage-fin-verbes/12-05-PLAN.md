# Plan 12-05 — Refonte de `AGENT.md` (niveau 3 du routage)

## But

Faire de `vibeflow-dev` un routeur **vers les verbes** et non plus vers la plomberie : une seule
source de vérité par intention. Rend vrai le critère de succès 1 du ROADMAP.

## Exigences couvertes

VERB-01, VERB-04 (rappel de la préséance côté agent).

## Tâches

1. **Réécrire la table de routage** : colonne « Action coulisse » (`gsd-*`) → colonne
   **« Verbe »** (`/vf-*`). Regroupement par famille pour tenir la densité :
   *amont & cadrage* · *construction* · *qualité & audits* · *cycle de vie projet* ·
   *contexte & session* · *design* · *mission multi-étapes*. Une ligne peut porter plusieurs
   formulations, **jamais** une cible `gsd-*`.
2. **Ajouter le renvoi doctrine** : intention non couverte par un verbe → consulter
   `.claude/agents/dev-orchestrator-references/intent-routing.md` (on-demand), puis déléguer.
   Remplacer l'actuel renvoi « en cas de doute, consulter `gsd-skills-index.md` » par ce renvoi-là
   (l'index reste cité comme inventaire factuel, en second rang).
3. **Rappeler la préséance** : une ligne dans les Garde-fous + une dans les Iron Laws pointant
   `rules/vf-verb-precedence.md`. Pas de duplication du contenu de la rule.
4. **Décision de conception — tension T3 ↔ VERB-01** (à écrire noir sur blanc dans le SUMMARY) :
   - T3(a) compte ≥ 11 **cibles canoniques `gsd-*` distinctes dans le fichier**, T3(b) ≥ 11 lignes
     d'intentions dans la table. VERB-01 et le critère de succès 1 portent explicitement sur **la
     table de routage**, pas sur le fichier entier.
   - **Décision retenue** : conserver le bloc *« Cibles canoniques figées (partagées avec les verbes
     `/vf-*`) »* en **fin d'agent**, hors table, en le requalifiant en *contrat de cohérence
     verbes ↔ cibles*. Il n'est pas un chemin de routage : l'agent route vers un verbe, le verbe
     connaît sa cible.
   - **Justification** : (a) VERB-01 est respecté à la lettre — zéro `gsd-*` dans la table ;
     (b) T3 reste vert sans être affaibli, donc on ne relâche pas un test existant pour faire passer
     un refactor ; (c) le bloc garde une valeur propre — c'est lui qui garantit que verbes et agent
     parlent des mêmes cibles.
   - **Alternative écartée** : réécrire T3 pour compter des verbes. Elle transforme un test de
     non-régression en test taillé pour le nouveau code, et fait perdre la couverture historique.
   - Le contrôle complémentaire (« la *table* ne contient aucun `gsd-*` ») est ajouté en 12-06 (T13).
5. **Vérifier la densité** après réécriture : `wc -l` ≤ 250. Si dépassement, déporter davantage de
   doctrine vers `intent-routing.md` — **jamais** l'inverse.

## Comment on vérifie (recette)

- Table propre → les lignes `^|` de la table de routage ne matchent pas `gsd-[a-z-]+`.
- `wc -l plugin/dev-orchestrator/AGENT.md` ≤ 250.
- `grep -c 'intent-routing.md'` ≥ 1 ; `grep -c 'vf-verb-precedence'` ≥ 1.
- `bash plugin/dev-orchestrator/scripts/tests/test-dev-orchestrator.sh` → **T3, T5, T7, T9, T10
  verts** (non-régression, c'est le point dur de ce plan).
- `bash plugin/conductor/scripts/check-agents.sh` vert (frontmatter `description`/`model`/`memory`
  intact, ADR-044).

## Risques / points d'attention

- **T3(b)** compte les lignes de **toutes** les tables du fichier, hors séparateurs et hors en-tête
  commençant par « Intention ». Renommer l'en-tête de colonne (« Intention » → autre chose) ferait
  compter la ligne d'en-tête comme une intention : garder l'en-tête `| Intention … |`.
- **T7** : le garde-fou first-use doit rester détectable hors commentaires (`first-use`/`premier
  usage`, `.planning`, `vf-init`, `new-project`). Une refonte trop agressive de la section le casse.
- **Densité** : 33 verbes dans une table à plat feraient exploser les 250 L. Le regroupement par
  famille n'est pas cosmétique, c'est la contrainte structurante du plan.
