## Contrat de l'équipe (figé à la planification ; source unique pour 69-02 à 69-08)

C1 — Sortie de `collectWho` : schéma `vibeflow/cockpit-who@2`, qui remplace `@1` dans `vf-cockpit-interface.json`
(P69-PL-18). Clés de tête requises : `schema`, `at`, `root`, `trees`, `fresh`, `fenetre` (nombre, 86400), `busy`,
`workers`, `sources`. `busy` = au moins un travailleur non `stale` dont `etat` n'est pas `termine`.

C2 — Travailleurs `session` et `subagent`, champs ajoutés :
- `etat` ∈ `actif`, `en-attente`, `termine`. Sous-agent : `termine` si `meta.finished === true` et fin (date de
  modification du `.jsonl`) depuis moins de `fenetre`, absent sinon ; `actif` si non terminé et écrit depuis moins de
  `fresh` ; `en-attente` si non terminé, silencieux depuis `fresh` ou plus, et ancêtre d'un agent présent `actif` ou
  `en-attente` ; tout autre non terminé silencieux est absent. Session : `actif` si écrite depuis moins de `fresh` ;
  sinon présente seulement comme racine d'au moins un sous-agent présent : `en-attente` si un descendant est `actif` ou
  `en-attente`, `termine` sinon (P69-PL-14).
- `parent` : sous-agent de `spawnDepth` ≥ 2 -> `meta.parentAgentId` ; `spawnDepth` 1 -> identifiant de la session ;
  session -> absent. `depth` = `meta.spawnDepth`.
- `dureeS` : secondes entre l'horodatage de la première ligne du transcript et `finAt` (terminé) ou `at` (sinon) ;
  absent si illisible. `finAt` : date ISO de fin, pour `termine` seulement.
- `action` : `{ verbe, cible }` pour `etat === 'actif'` seulement (table C5) ; absent sinon.
- `rattachement` (sous-agent) : `{ etat: 'rattache', source: 'registre'|'mandat', dag: '<chemin relatif du DAG>',
  noeud: '<id>' }` ou `{ etat: 'non-rattache', raison: 'sans-citation'|'inconnu'|'ambigu' }`.
- Une entrée de registre (`kind: 'registered'`) dont l'identifiant est celui d'un sous-agent présent n'est plus émise ;
  les autres restent. Toute clé d'un travailleur figure dans `travailleur.requis` ∪ `travailleur.optionnels`.

C3 — Forme Claude Code (`claudeCode` du contrat) : `metaSousAgent.requis` = `agentType`, `description`, `spawnDepth`,
`toolUseId`, `requestShape` (sous réserve de la mesure de 69-03, P69-PL-16) ; `metaSousAgent.requisSiProfondeur` =
`{ "parentAgentId": 2 }` ; `metaSousAgent.booleensFacultatifs` = `["finished"]` ; `transcriptSousAgent.requis` =
`["isSidechain", "agentId"]` lus sur la première ligne (`isSidechain === true`, `agentId` égal à l'identifiant du
fichier) ; `verifieSur` = version mesurée. Un sous-agent hors forme, ou dont `parentAgentId` désigne un agent absent du
dossier de la session, n'entre pas dans l'arbre et compte dans `formeInconnue` ; `sources.sessions.etat` vaut
`forme-inconnue` dès que `formeInconnue > 0`.

C4 — Graphe de l'onglet Équipe `vibeflow/cockpit-equipe@1` (format du viewer) : `meta.vfTab === 'equipe'` ; cartes
`se-<idSession>` (racines) et `ag-<idAgent>` (parent = carte de son parent) ; une carte `<idCarte>~termines` intitulée
« Terminés depuis moins de 24 h (N) » sous chaque carte qui a au moins un enfant `termine`, portant ces enfants ; `st` :
`actif` et `en-attente` -> `active`, `termine` -> `done` ; aucun élément `files`. Servi par `GET /equipe.html` (en
mémoire, jamais écrit sur disque), titre « VibeFlow · Équipe ».

C5 — Dernière action, table fermée (libellés provisoires, P69-PL-19) : `Read` « lit » ; `Write`, `Edit`, `MultiEdit`,
`NotebookEdit` « modifie » ; `Grep`, `Glob` « cherche dans » ; `Bash`, `bash` « lance une commande » (cible vide,
P69-PL-12) ; `Agent`, `Task` « lance un agent » (cible = `subagent_type`) ; `SendMessage` « écrit à » (cible = `to`) ;
`WebFetch` « consulte une page » (cible = nom d'hôte seul) ; `WebSearch` « cherche sur le web » ; `Skill` « utilise le
skill » (cible = `skill`) ; `mcp__<serveur>__<outil>` « utilise » (cible = `<serveur>`) ; autre « utilise un outil ».
Cible de chemin relative à la racine du lab, sinon « un fichier hors du lab » ; toute cible bornée à 120 caractères et
masquée.

C6 — Rattachement (P69-D-15, P69-PL-11) : index des nœuds construit par `lireDags(root, layout)` (69-01) ; le registre
(`orphans`), quand il porte un nœud pour l'agent, décide seul (candidats : DAG du compartiment de l'appel `orphans`,
tous pour le dépôt) ; sinon les citations du mandat (première ligne du transcript), motif fixe jamais construit depuis le
lab : « nœud » ou « noeud » (toute casse), deux-points facultatif, puis un identifiant entre accents graves, ou
`--node=<id>` ; identifiant `[A-Za-z0-9][A-Za-z0-9._-]{0,63}`. Présent dans exactement un DAG -> `rattache` ; dans aucun
-> `inconnu` ; dans plusieurs, ou plusieurs citations résolues différemment -> `ambigu` ; aucune citation ->
`sans-citation`.

C7 — Transcript : `GET /api/vf/transcript?id=<idAgent>` (GET seul, derrière Host, même origine et jeton en en-tête) ;
identifiant hors `ID_RE` -> 400 `{erreur:'id-invalide'}` ; absent de la collecte (fenêtre comprise) -> 200
`{schema, id, erreur:'inconnu'}` ; sinon 200 `vibeflow/cockpit-transcript@1` `{ schema, id, mandat, messages, outils,
tronque }` : `mandat` = contenu chaîne de la première ligne `user` (masqué, ≤ 8 000 caractères) ; `messages` = blocs
`text` des lignes `assistant` (masqués, ≤ 2 000 caractères, 50 derniers) ; `outils` = `[{ outil, verbe, cible }]`
(table C5, 200 derniers) ; jamais `tool_result`, `toolUseResult`, `api-request-blob`, `attachment`, `thinking` ni
`input` ; `Cache-Control: no-store` ; jamais journalisé ; lecture bornée (tête 256 Kio, queue 8 Mio), `tronque` vrai
au-delà.

C8 — Clés interdites du flux : `interdits` de `vibeflow/cockpit-who@2` = `["doing", "mandat", "messages", "outils"]` ;
le serveur refuse d'émettre tout objet qui en porte une, à toute profondeur, liste lue du contrat (contrat illisible :
rien n'est émis).

C9 — Couche d'affichage : `ui/71-vf-equipe-rendu.js` définit `window.__vfEquipeRendu = { arbre(workers, h),
agentsDuNoeud(workers, ref, h), transcript(donnees, doc), pied(w) }` sans dépendance au viewer. `arbre` rend un
`<div class="vf-arbre">` où chaque agent est un élément `data-vf-agent="<id>"` imbriqué dans le `.vf-arbre-enfants` de
son parent ; les terminés dans un `<details class="vf-termines">` sans attribut `open`, dont le résumé contient
« Terminés depuis moins de 24 h » ; un agent rattaché porte un lien `href="project.html#r=<encodeURIComponent('f:' + dag
+ '#' + noeud)>"` ; chaque agent un lien `href="equipe.html#r=<encodeURIComponent('n:ag-' + id)>"` ; sessions et
sous-agents gardent le bouton `data-vf-doing`. `agentsDuNoeud` rend une chaîne vide si aucun agent n'est rattaché à
`ref`, sinon les liens vers leurs cartes. `transcript` construit un `DocumentFragment` par `doc.createElement` (balises
`div`, `h4`, `p`, `ul`, `li`, `pre`, `span` seulement) et `textContent`, jamais `innerHTML`. `ui/72-vf-equipe.js` porte la
logique de l'onglet Équipe. Le tiroir garde le titre « Au travail (N) », N = agents `actif`.

C10 — Onglets : `00-vibeflow.js` reconnaît `meta.vfTab === 'equipe'` et rend un troisième lien `equipe.html` intitulé
« Équipe ».
