### 2.2 Correction minimale de `eviter` (`TI` l.47) : `#ask` devient un obstacle

Comportement ajouté, rien d'autre : la pastille se pose 8 px au-dessus de `#ask` quand elle le recouvre ; `#zoom` continue de remonter au-dessus de la pastille (code v1.3.3 conservé, le littéral **`if (recouvre) z.style.bottom`** reste tel quel : mutant M-PASTILLE-SUR-ZOOM intact) ; la puce se pose au-dessus du plus haut des deux obstacles. Code testé (injecté dans Chromium, remplace le corps de `eviter` jusqu'à `const eviterTout`) :

```js
const eviter = (n) => {
  const z = document.getElementById('zoom'), b = z ? z.getBoundingClientRect() : null;
  // 71.5 (P71.5-D-06) : la barre de question #ask est un obstacle de plus, lu comme le zoom, avec la même marge de 8
  const k = document.getElementById('ask'), kb = k ? k.getBoundingClientRect() : null;
  const sur = (a, o) => !!o && o.width > 0 && a.left < o.right && a.right > o.left && a.top < o.bottom && a.bottom > o.top;
  if (n === d.pastille) {
    if (z) z.style.bottom = '';
    n.style.bottom = '';
    document.body.classList.remove('vf-term-haut');
    if (!n.parentNode || n.hidden) return;
    const surAsk = sur(n.getBoundingClientRect(), kb);
    if (surAsk) n.style.bottom = Math.round(window.innerHeight - kb.top + 8) + 'px';
    document.body.classList.toggle('vf-term-haut', surAsk);
    if (!z) return;
    const a = n.getBoundingClientRect(), s = document.getElementById('stage'), fond = s ? s.getBoundingClientRect().bottom : window.innerHeight, zb = z.getBoundingClientRect();
    const recouvre = zb.width > 0 && a.left < zb.right && a.right > zb.left && a.top < zb.bottom && a.bottom > zb.top;
    if (recouvre) z.style.bottom = Math.round(fond - a.top + 8) + 'px';
    document.body.classList.toggle('vf-term-haut', recouvre || surAsk);
    return;
  }
  if (!n.parentNode || n.hidden) return;
  n.style.bottom = '';
  const a = n.getBoundingClientRect();
  const haut = Math.min(sur(a, b) ? b.top : Infinity, sur(a, kb) ? kb.top : Infinity);
  if (haut < Infinity) n.style.bottom = Math.round(window.innerHeight - haut + 8) + 'px';
};
```
- `vf-term-haut` (qui remonte la visite de 44, `ST` l.48) est posé aussi quand la pastille est relevée au-dessus de `#ask` : sans cela la visite (bas 76) recouvrait la pastille relevée (mesuré : 8 largeurs rouges sur `#tour` avant ce correctif).
- **Re-déclenchement** (sinon la correction est périmée dès que le panneau s'ouvre après le chargement) : après `window.addEventListener('resize', eviterTout);` ajouter
  ```js
  { const ask = document.getElementById('ask'); if (ask) { if (window.ResizeObserver) new ResizeObserver(eviterTout).observe(ask); ask.addEventListener('transitionend', eviterTout); } }
  ```
  `ResizeObserver` couvre l'apparition/disparition (la barre passe en `display: none` tiroir ouvert et à ≤ 700 feuille ouverte) et le changement de largeur ; `transitionend` est indispensable : `left` et `width` de la barre transitionnent 450 ms, le dernier rappel du `ResizeObserver` tombe avant la fin de `left` (mesuré : pastille restée relevée à 1200 px, panneau refermé, sans lui ; avec lui, 10 relevés sur 10 propres). Aucune boucle : `eviter` n'écrit jamais sur `#ask`.
- Tiroir ouvert : la pastille est masquée, `#ask` aussi (`body.vf-term-ouvert #ask { display: none }`) ; à la fermeture `eviter(d.pastille)` (déjà appelé l.~142) repose la même position : T21.4 (« même bas ») inchangé.
