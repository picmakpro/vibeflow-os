## Ce qui est livré

Deux commits : `0c65eb1` (fix des deux scripts) et `a98e0e3` (les deux suites).

**`detect-gsd-engine.sh`** — une **priorité 2bis** est insérée entre le repli racine legacy
(priorité 2) et le signalement de migration (priorité 3). Elle énumère les compartiments via
`vf_ws_enumerate`, puis fait deux passes sur la liste : d'abord un compartiment dont le `STATE.md`
porte `gsd_state_version` (→ rc=0, « le compartiment « X » appartient à GSD »), à défaut un
compartiment dont le `STATE.md` porte `workstream:`+`created:` (→ rc=0, message qui **énonce le
fait constaté et dit explicitement qu'il ne classe pas** le compartiment). `has_frontmatter_key`
est réutilisée **telle quelle**, jamais réécrite. L'en-tête documente la nouvelle couverture du
code 0. Priorités 1, 2, 3 et 4 : intactes.

**`check-planning-state.sh`** — le repli racine (`STATE_FILE="$PLANNING_DIR/STATE.md"` → message
ABSENT) est **bordé**, patron exact de `check-divergence.sh` (`if [ -d "$PLANNING/phases" ]`). Sur
rc=0 de la primitive : si `.planning/phases/` existe, le message ABSENT est conservé tel quel
(legacy encore en jeu) ; sinon, `say_diag` sur stderr (« dépôt partitionné, N compartiment(s) …»)
et `exit 0`. Sur rc=3 : comportement d'avant la phase, **à l'identique, sans une ligne de plus** —
c'est l'état NOMINAL d'un dépôt non partitionné (D-01), le message ABSENT y dit vrai. Sur rc=2 et
sur un code imprévu : `hook_exit 2` (contrat de sortie **inchangé**) mais le message **n'emprunte
plus le mot ABSENT** — il dit « NON VÉRIFIABLE » et nomme quoi inspecter.

Le bloc `--defer-to-gsd` (l.~88-97) n'est **pas** touché : ce n'était pas le bug.

## Le piège que ce plan évitait, et la mesure qui le montre

La rédaction naïve (`WS_LIST="$(vf_ws_enumerate … 2>/dev/null)"` puis `[ -n "$WS_LIST" ]`) jette
le rc **et** stderr. Or `rc=2 lien symbolique`, `rc=2 vide après filtrage` et `rc=3 non partitionné`
produisent **tous les trois** un stdout vide : un `.planning/workstreams` détourné en lien
symbolique redeviendrait silencieusement « dépôt non partitionné ». Mesure sur les scripts
d'AVANT, fixture `workstreams` → lien symbolique : `detect-gsd-engine.sh` rc=3 / **stderr vide**,
`check-planning-state.sh` rc=2 / stdout « … est ABSENT … » / **stderr vide**. Après :
`annonce_detect=2 annonce_planning_state=2 absent_menteur=0`.
