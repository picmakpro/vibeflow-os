## Artifacts this phase produces

`plugin/cockpit/scripts/vf-cockpit-git-graphe.mjs` (neuf, sous 250 lignes) :
- `FORMAT_JOURNAL` = `'%H%x00%P%x00%at%x00%an%x00%s'` ; `MOTIF_SHA` = `/^[0-9a-f]{40}$/` (option `motif` pour sha256, `{64}`).
- `lireJournal(sortie, { motif })` -> `{ ok: true, commits: [{ h, p: [sha…], at, an, s }] }` ou `{ ok: false, raison }` : découpe
  sur `\0`, un seul vide final toléré, paquets de 5 ; `h` et chaque parent au motif, `at` entier, sinon `ok:false`.
- `lireRefs(sortie, { champs })` -> `{ ok, refs: [objet aux noms de `champs`] }` : une ligne par ref (un nom de ref ne contient ni
  saut de ligne ni contrôle), champs séparés par `\0`, nombre exact sinon `ok:false` ; le premier champ commence par `refs/`.
- `lireWorktrees(sortie)` -> `{ ok, worktrees: [{ chemin, head, branche, detache, nu, verrouille }] }` pour
  `worktree list --porcelain -z` (enregistrements séparés par un champ vide, clés `worktree`, `HEAD`, `branch`, `detached`, `bare`,
  `locked`, `prunable`).
- `ordonner(listes)` -> un tableau de commits uniques, chaque enfant avant ses parents présents, départage `at` décroissant puis `h`.
- `placer(commits, { couloirsMax = 6 } = {})` -> `{ rangees: [{ h, col, entrants: [k], sortants: [{ de, vers, parent }], largeur,
  ouvertBas: [k], fusion, racine }], couloirsMax, ouvertsEnBas, racines, replies }` (algorithme du §2 de la recherche ; au-delà de
  `couloirsMax`, la colonne est rabattue sur la dernière et `replies` compte les rangées concernées, pour le « +N » de l'UI).
- `etiquettes(refs, { head, worktrees })` -> `Map<sha, [{ type: 'head'|'locale'|'distante'|'tag', nom, courante, worktree }]>`,
  ordre HEAD, locales, distantes, tags, puis nom (ordre des points de code).
- `teinte(nom)` -> entier de 1 à 5, empreinte stable du nom de la ref de tête (0 réservé à la branche de base, posé par 78-05).
