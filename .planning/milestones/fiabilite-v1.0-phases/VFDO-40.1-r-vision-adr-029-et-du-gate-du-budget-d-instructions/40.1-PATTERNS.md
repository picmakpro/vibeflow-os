# Phase 40.1 : Révision ADR-029 et du gate du budget d'instructions - Pattern Map

**Mapped :** 2026-09-16
**Fichiers analysés :** 5 fichiers-noyau nommément cadrés (gate, suite, CI, baseline, ADR) + 3
familles de fichiers dérivées par recensement (`git grep -n -w 250`, doctrine `40.1-CONTEXT.md`) +
1 patron transverse externe déjà en production.

**Nature de la phase — lire avant d'utiliser cette carte.** Cette phase ne crée AUCUN fichier
nouveau : elle **révise** des fichiers existants (gate bash, sa suite, une étape CI, de la doctrine
Markdown). Il n'y a donc pas d'« analogs pour fichier neuf » au sens classique — la carte ci-dessous
répond à une question différente mais équivalente pour le planner : **pour chaque fichier à modifier,
quel patron déjà présent dans CE dépôt (parfois dans le fichier lui-même, parfois dans un fichier
voisin) doit gouverner la forme de l'édition ?** Le patron dominant, cité explicitement par D-05 du
`40.1-CONTEXT.md`, est le couple warn/block de `plugin/software-architecture/scripts/check-file-size.sh`
— **à copier fidèlement** (mêmes noms de variables d'environnement, même structure conditionnelle),
pas à réinventer.

**Analogs trouvés :** 5/5 fichiers-noyau ont un patron concret extrait ci-dessous ; les 3 familles de
fichiers dérivés (suites de modules, auditeur distribué, doctrine vivante) sont couvertes par un
patron par famille (pas fichier par fichier — ils sont trop nombreux et doivent être re-dérivés par
commande, jamais recopiés d'une table figée, cf. `40.1-CONTEXT.md` et `40.1-RESEARCH.md`).

## Pattern Assignments

### `plugin/conductor/scripts/check-instruction-budget.sh` (gate, transform)

**Analog structurel externe :** `plugin/software-architecture/scripts/check-file-size.sh` (lu
intégralement — 109 lignes).

**Patron warn/block à copier** (`plugin/software-architecture/scripts/check-file-size.sh:25-26`) :
```bash
WARN="${VF_ARCH_WARN:-250}"
BLOCK="${VF_ARCH_BLOCK:-300}"
```
et son application (`:50-61`) :
```bash
if [ "$n" -ge "$BLOCK" ]; then
  echo "  ✗ $f : $n lignes (≥ $BLOCK) — BLOCAGE : découper (SRP) ou tracer la dette"
  violations=$((violations + 1))
elif [ "$n" -ge "$WARN" ]; then
  echo "  ⚠ $f : $n lignes (≥ $WARN) — surveiller, approche du seuil de découpe"
  warnings=$((warnings + 1))
fi
```
Point dur du patron à reproduire dans `check-instruction-budget.sh` : **seul `violations` (via
`BLOCK`) fait sortir en code d'erreur** (`:102-104` : `if [ "$violations" -gt 0 ]; then exit 2; fi`) —
`warnings` n'influence jamais le code de sortie. C'est exactement le contrat D-05 pour l'axe lignes :
un avertissement 251-300 qui n'incrémente jamais `OVERRUN_COUNT`.

**Comptage de lignes — ne jamais utiliser `wc -l`** (patron déjà en place des deux côtés) :
```bash
# check-file-size.sh:48 :
n=$(awk 'END { print NR }' "$f" 2>/dev/null || echo 0)
# check-instruction-budget.sh:160-162 :
lines_count() { # <file> -> nombre de lignes du fichier ENTIER, jamais wc -l (sous-compte sans \n final)
  awk 'END { print NR }' "$1" 2>/dev/null || echo 0
}
```
`check-instruction-budget.sh` a déjà ce patron — ne pas le modifier, seulement modifier ce qui
consomme son résultat.

**Constante à modifier** (`plugin/conductor/scripts/check-instruction-budget.sh:68-73`) :
```bash
# Plafond ADR-029 (charte de densite : agents <= 250 lignes). Arme par la MEME sentinelle que la
# baseline (D-05) : la limite effective de lignes d'un fichier est le plus petit de sa baseline et
# de cette constante. Une baseline de lignes superieure a 250 ne peut jamais legaliser un
# depassement par simple mesure — voir verdict DEPASSEMENT-ADR029 plus bas, qui prime toujours sur
# la comparaison a la baseline.
VF_BUDGET_LINE_CAP=250
```
→ `VF_BUDGET_LINE_CAP=300` ; ajouter une constante sœur `VF_BUDGET_LINE_WARN=250` juste à côté,
même style de commentaire ; réécrire le commentaire (« limite effective = min(baseline, plafond) »
devient « limite = plafond seul, `bl_lines` n'est plus jamais comparé, uniquement affiché (D-H6) » —
formulation explicite recommandée par le Pitfall 1 de RESEARCH.md pour empêcher une régression
future).

**Verdict — bloc à réviser** (`plugin/conductor/scripts/check-instruction-budget.sh:296-317`,
citation verbatim complète) :
```bash
  # Plafond absolu ADR-029 : prime sur TOUT le reste, y compris une baseline egale au courant —
  # une baseline de lignes > 250 ne legalise jamais le depassement par simple mesure (D-05).
  verdict="OK"
  if [ "$lines" -gt "$VF_BUDGET_LINE_CAP" ]; then
    verdict="DEPASSEMENT-ADR029"
  elif [ "$has_baseline" -eq 0 ]; then
    verdict="SANS-BASELINE"
  else
    line_over=0; instr_over=0
    [ "$lines" -gt "$bl_lines" ] && line_over=1
    [ "$instr" -gt "$bl_instr" ] && instr_over=1
    if [ "$line_over" -eq 1 ] && [ "$instr_over" -eq 1 ]; then
      verdict="DEPASSEMENT-LIGNES+INSTR"
    elif [ "$line_over" -eq 1 ]; then
      verdict="DEPASSEMENT-LIGNES"
    elif [ "$instr_over" -eq 1 ]; then
      verdict="DEPASSEMENT-INSTR"
    elif [ "$lines" -lt "$bl_lines" ] || [ "$instr" -lt "$bl_instr" ]; then
      verdict="MARGE"
    fi
  fi
```
→ retirer `line_over` et les deux verdicts `DEPASSEMENT-LIGNES*` du chemin qui alimente `rc` ;
insérer le test de zone d'avertissement 251-300 **avant** la branche `has_baseline`, en respectant
le point dur du garde-fou : **aucun libellé d'avertissement ne doit commencer par `DEPASSEMENT-`**
(sinon il tombe dans le `case` qui incrémente `OVERRUN_COUNT`, cité verbatim
`check-instruction-budget.sh:326-328` :
```bash
case "$verdict" in
  DEPASSEMENT-*) OVERRUN_COUNT=$((OVERRUN_COUNT + 1)) ;;
esac
```
) — nom exact du libellé laissé à Claude's Discretion (`40.1-CONTEXT.md`).

**Colonne lignes conservée, jamais comparée (D-H6)** — l'affichage existant reste inchangé
(`check-instruction-budget.sh:330`) :
```bash
printf '%s | %s | %s | %s | %s | %s\n' "$rel" "$lines" "$bl_lines" "$instr" "$bl_instr" "$verdict"
```

**Exit-code contract — inchangé** (`check-instruction-budget.sh:350-361`, citation verbatim) :
```bash
RC=0
if [ "$NONVERIF_COUNT" -gt 0 ]; then
  RC=2
elif [ "$ARMED" -eq 1 ] && [ "$BASELINE_CONTRACT_BAD" -eq 1 ]; then
  RC=2
elif [ "$ARMED" -eq 1 ] && [ "$OVERRUN_COUNT" -gt 0 ]; then
  RC=1
elif [ "$ARMED" -eq 1 ]; then
  RC=0
else
  RC=3
fi
```
Ne pas toucher — il continue de lire `OVERRUN_COUNT` seul, ce qui suffit si le libellé
d'avertissement est correctement exclu du `case`.

**En-tête de commentaire du fichier** (`:1-25`, patron de documentation du rôle du gate) — à
compléter pour mentionner la zone d'avertissement 251-300 en plus des deux métriques déjà décrites.

### `plugin/conductor/scripts/tests/test-check-instruction-budget.sh` (test, batch)

**Patron de mutant opposable à copier tel quel** (MUT-2 existant sert de gabarit direct pour
inventer MUT-5, et pour transformer MUT-2 lui-même en son inverse) — citation verbatim
(`:449-467`) :
```bash
MUT2_OLD='    [ "$lines" -gt "$bl_lines" ] && line_over=1'
MUT2_NEW='    [ "0" -eq "1" ] && line_over=1'
awk -v old="$MUT2_OLD" -v new="$MUT2_NEW" '{ if ($0 == old) { print new } else { print } }' "$SCRIPT" > "$MUTD/mut2-lignes.sh"
D="$(mk_root mut2)"
std_agent "$D"
w_armed "$D"
printf 'plugin/demo/agents/a.md\t3\t1\n' | w_baseline "$D"
if cmp -s "$MUTD/mut2-lignes.sh" "$SCRIPT"; then
  ko "MUT-2 comparaison LIGNES neutralisee" "mutation differente de l'original (cmp)" "mutant identique a l'original — NON OPPOSABLE"
elif ! bash -n "$MUTD/mut2-lignes.sh" 2>/dev/null; then
  ko "MUT-2 comparaison LIGNES neutralisee" "bash -n OK sur le mutant" "syntaxe invalide — pas une preuve"
else
  TARGET="$MUTD/mut2-lignes.sh"; run "$D" >/dev/null 2>&1; rc_mut=$?
  TARGET="$SCRIPT"; run "$D" >/dev/null 2>&1; rc_orig=$?
  if [ "$rc_mut" -eq 0 ] && [ "$rc_orig" -eq 1 ]; then
    ok "MUT-2 ... rc=$rc_mut, ROUGE sur l'original (rc=$rc_orig)"
  else
    ko "MUT-2 ..." "rc_mutant=0 rc_original=1" "rc_mutant=$rc_mut rc_original=$rc_orig"
  fi
fi
```
Structure invariable du patron mutant dans ce fichier, à répliquer pour tout nouveau mutant :
(1) définir `_OLD`/`_NEW` en littéral shell exact, (2) `awk` ligne-à-ligne pour produire le fichier
muté, (3) rejeter le mutant s'il est identique à l'original (`cmp -s`) — **jamais opposable** — ou
syntaxiquement invalide (`bash -n`), (4) comparer `rc` du mutant et de l'original sur une même
fixture ciblée. Ce même patron `cmp -s` + `bash -n` sert MUT-1, MUT-3, MUT-4 (inchangés par cette
phase) et doit servir le nouveau MUT-5 (D-05 : rendre bloquante la zone d'avertissement).

### Warn/block gradué (source du patron pour tout le périmètre BUDG-04/D-05)
**Source :** `plugin/software-architecture/scripts/check-file-size.sh:25-26,44-61`
**S'applique à :** `check-instruction-budget.sh` (axe lignes uniquement, D-06 : ne pas toucher

```bash
WARN="${VF_ARCH_WARN:-250}"
BLOCK="${VF_ARCH_BLOCK:-300}"
...
if [ "$n" -ge "$BLOCK" ]; then
  # bloquant : incrémente le compteur qui pilote exit != 0
```

branche BLOCK ; la branche WARN incrémente au plus un compteur d'affichage séparé (`warnings`).
