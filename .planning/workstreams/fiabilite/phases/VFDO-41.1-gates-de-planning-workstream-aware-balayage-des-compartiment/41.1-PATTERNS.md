## Pattern Assignments

### `plugin/planning-core/scripts/workstream-policy.sh` — add `vf_ws_enumerate`

**Analog:** the file's own existing sibling functions (no external analog needed — this is additive to an established single-source-of-truth file).

**Why this file, why here (already argued in the file's own header, lines 1-31):** four gates used
to carry divergent copies of name-resolution logic; the fix was centralizing in `planning-core`
because it has zero cross-module dependencies. D-01 applies the exact same argument to
*enumeration*: `check-divergence.sh` already sources this file via a two-candidate search (see
below), so the dependency direction (`conductor` → `planning-core`) already exists — adding the
enumeration primitive here reuses that edge instead of creating a new one.

**Sibling primitive to model the signature/contract on** (`vf_ws_path_nolink`, lines 226-230):
```bash
# Primitive : <chemin> existe-t-il SANS être un lien symbolique ?
#   0 = présent et non-lien · 1 = absent · 2 = lien symbolique (y compris pendant : `[ -L ]` est vrai
#   là où `[ -e ]` est faux, l'ordre des tests ci-dessous est donc porteur).
vf_ws_path_nolink() { # <chemin>
  [ -L "$1" ] && return 2
  [ -e "$1" ] || return 1
  return 0
}
```

**Sibling primitive with the closest exit-code shape (`vf_ws_dir_resolve`, lines 239-251)** — reuse
this for how `vf_ws_enumerate` should call `vf_ws_path_nolink` on both `workstreams/` itself and on
each `workstreams/<nom>/` entry, and how it documents its 0/1/2 contract inline:
```bash
vf_ws_dir_resolve() { # <planning_dir> <nom>
  local root="$1/workstreams" dir="$1/workstreams/$2" rc=0
  VF_WS_DIR=""
  vf_ws_path_nolink "$root"; rc=$?
  [ "$rc" -eq 2 ] && { VF_WS_REASON="workstreams-lien-symbolique"; return 2; }
  [ "$rc" -eq 1 ] && return 1
  vf_ws_path_nolink "$dir"; rc=$?
  [ "$rc" -eq 2 ] && { VF_WS_REASON="compartiment-lien-symbolique"; return 2; }
  [ "$rc" -eq 1 ] && return 1
  [ -d "$dir" ] || return 1
  VF_WS_DIR="$dir"
  return 0
}
```

**Contract to implement, from D-01 verbatim (41.1-CONTEXT.md lines 34-47):**
- Signature: `vf_ws_enumerate <planning_dir>` — prints one absolute path per compartment **present
  on disk**, one per line, via `find`/glob on `<planning_dir>/workstreams/*/`.
- Filters every entry through `vf_ws_path_nolink` (code 2 = symlink → excluded, stderr message) —
  never followed, same posture as existing functions.
- Never reads `GSD_WORKSTREAM`, `VF_WORKSTREAM`, `VF_STATE_WORKSTREAM`, nor the
  `.planning/active-workstream` pointer — disk-only.
- Exit codes: `0` = at least one compartment listed on stdout; `3` = SILENCE,
  `<planning_dir>/workstreams/` absent (same code as `check-divergence.sh`'s own SILENCE, see
  below); `2` = present but unreadable/symlink/empty-after-filter — **never a disguised 0**. This
  closes WSAW-01 (see `check-divergence.sh` pattern assignment below).

**Error-handling / diagnostic style to copy** — every refusal in this file is *audible* (stderr
message naming the reason) and stored in an enumerated `VF_WS_REASON`, never silent (see the file's
own doctrine block, lines 34-55, and `vf_ws_read_pointer`, lines 168-190, for the three-refusal
pattern: symlink / non-regular / oversized, each with its own named reason).

### `plugin/conductor/scripts/check-divergence.sh` — dedup loops, adopt `vf_ws_enumerate`, close WSAW-01

**Analog:** itself, pre-refactor — the two loops to delete are both in this file.

**Sourcing pattern to preserve unchanged** (two-candidate search, lines 94-102) — this is the
integration point D-01 explicitly calls out (CONTEXT.md `<code_context>` "Integration Points"):
```bash
WS_POLICY=""
for _cand in "$(dirname "$0")/workstream-policy.sh" \
             "$(dirname "$0")/../../planning-core/scripts/workstream-policy.sh"; do
  [ -r "$_cand" ] && { WS_POLICY="$_cand"; break; }
done
[ -n "$WS_POLICY" ] \
  || { echo "[check-divergence] workstream-policy.sh introuvable — politique non chargeable, non vérifiable" >&2; exit 2; }
# shellcheck source=/dev/null
. "$WS_POLICY"
```

**SILENCE-before-sourcing pattern to preserve** (lines 88-92) — `vf_ws_enumerate` must exit `3` under
the identical precondition:
```bash
if [ ! -e "$WS_ROOT" ]; then
  exit 3
fi
```

**Copy #1 to delete — main body loop (lines 296-310):**
```bash

  [ -d "$_wsdir" ] || continue
  _wsname="$(basename "$_wsdir")"
  vf_ws_path_nolink "$_wsdir"; _rc=$?
  if [ "$_rc" -eq 2 ]; then
    echo "[check-divergence] compartiment « $_wsname » est un lien symbolique — refus de le suivre, ignoré" >&2
    continue
  fi
  [ "$_rc" -eq 0 ] || continue
  CHECKED=1
  check_s2 "$_wsname" "$_wsdir/phases" || true
  check_s4a "$_wsname" "$_wsdir/phases" "$_wsdir/ROADMAP.md" || true
  check_s4b "$_wsname" "$_wsdir/phases" "$_wsdir/STATE.md" || true
done
```

**Copy #2 to delete — `check_s5()`'s independent loop (lines 250-263):**
```bash
for wsdir in "$WS_ROOT"/*/; do
  [ -d "$wsdir" ] || continue
  wsname="$(basename "$wsdir")"
  vf_ws_path_nolink "$wsdir"; rc=$?
  [ "$rc" -eq 0 ] || continue
  [ -d "$wsdir/phases" ] || continue
  ...
done
```
Both replaced by iterating over `vf_ws_enumerate "$PLANNING"` output (one absolute compartment path
per line, already symlink-filtered — the inline `vf_ws_path_nolink` calls inside these two loops
become redundant and are dropped, not duplicated a third time).

**WSAW-01 gap to close (lines 120, 322-334)** — `CHECKED` is initialized to `0` and only flips to
`1` inside a loop body; if `$WS_ROOT` exists but every entry is filtered out (all symlinks, or the
glob matches nothing), neither loop body ever executes, `CHECKED` stays `0`, and execution falls
through to:
```bash
if [ "$CHECKED" -eq 1 ]; then
  echo "[check-divergence] conforme — compartiment(s) inspecté(s), aucun signal S2/S4/S5" >&2
else
  echo "[check-divergence] $WS_ROOT présent mais vide — rien à inspecter" >&2
fi
exit 0
```
This is the disguised-0 bug D-01 names explicitly: once `check-divergence.sh` calls
`vf_ws_enumerate` instead of its own loop, a `vf_ws_enumerate` return of `2` (present but
unreadable/empty-after-filter) must propagate to `check-divergence.sh` exiting `2`, **not** falling
into this `else` branch and exiting `0`.

**Exit-code header block to keep verbatim (lines 44-52)** — this is the documentation convention
every workstream-aware gate in this phase must match:
```
#   0  = conforme — au moins un compartiment a été inspecté, aucun de S2/S4/S5 n'a signalé.
#   1  = DIVERGENCE constatée — au moins un de S2/S4/S5 a signalé (message stderr précise lequel,
#        et nomme le(s) numéro(s) impliqué(s) sous leur forme NORMALISÉE).
#   2  = NON VÉRIFIABLE — hors dépôt git, `.planning/` illisible, `workstreams/` illisible ou lien
#        symbolique, `workstream-policy.sh` introuvable. Jamais un 0 de complaisance.
#   3  = SILENCE — `.planning/workstreams/` absent : dépôt non partitionné, rien à vérifier.
#   64 = erreur d'usage (argument inconnu, option sans valeur).
```

### `plugin/conductor/scripts/check-planning-consumers-registered.sh` (new lint, WSAW-04)

**Analog:** `scripts/check-machine-paths.sh` — near-exact match on role (repo-hygiene lint) and data
flow (sweep every git-tracked file for a literal pattern, compare hits against a closed list, allow
an escape-hatch marker). Only the directory differs (root `scripts/` = repo-only tooling vs.
`plugin/conductor/scripts/` = distributed to labs) — irrelevant to the pattern itself, since this new
lint's *subject* (planning-path references across `plugin/`) only makes sense measured against this
repo, same as `check-machine-paths.sh`.

**Universe-not-empty guard to copy** (lines 106-120) — every repo-wide sweep in this codebase asserts
its own universe is non-trivial before rendering any verdict, exactly the anti-vert-à-vide discipline
CONTEXT.md's `<code_context>` "Established Patterns" section calls out generally:
```bash
git -C "$ROOT" ls-files -z > "$TMP_LIST" 2>/dev/null || true
UNIVERS="$(LC_ALL=C tr '\0' '\n' < "$TMP_LIST" | LC_ALL=C awk 'END { print NR+0 }')"
if [ "${UNIVERS:-0}" -eq 0 ]; then
  echo "[check-machine-paths] aucun fichier suivi sous $ROOT — cible vide, NON VÉRIFIABLE (jamais un vert)" >&2
  exit 2
fi
```

**Escape-hatch marker pattern to copy** (lines 86-89, 127) — D-03 calls for excluding `tests/` and
fixture `mktemp` blocks; model this on the closed-enumeration/marker discipline already used here:
```bash
HATCH="vf-allow-machine-path"
...
index($0, HATCH) > 0 { next }
```
(rename to something like `vf-allow-unregistered-planning-path` if an escape hatch is needed, though
D-03's spec is closer to a directory exclusion — `hors tests/, hors fixtures mktemp` — than a
per-line marker; keep the *closed enumeration* discipline regardless of which form is chosen.)

**Why `awk`, never `grep`, for the sweep (lines 41-43, load-bearing, copy verbatim reasoning):**
```
# PAS DE `grep` : le `grep` de certains runtimes de dev est proxifié et TRONQUE silencieusement
# (mesuré sur ce poste : 1 ligne rendue sur 91). Un gate qui compte sur un outil qui tronque rend
# un vert à vide. Tout le balayage passe par `awk`, qui lit les fichiers lui-même.
```
This directly matches CONTEXT.md `<code_context>` "Discipline de fixture" note: "jamais `diff` (ce
poste a un `diff` proxifié qui ment)" — the same proxied-tool distrust applies to `grep` here and
must carry into the new lint.

**Exit code contract to replicate** (lines 48-53): `0` = every referenced planning path is
registered; `1` = at least one unregistered reference found (listed on stderr); `2` = NON VÉRIFIABLE
(not a git repo, or empty universe); `64` = usage error. This is the same 0/1/2/64 shape as
`check-divergence.sh` minus the `3` SILENCE case (a lint with nothing to scan is still a usable
universe of zero references found — arguably `0`, not `3`; confirm against D-03's exact intent when
implementing, since D-03 doesn't specify a SILENCE code).

**What to grep for, per D-03 verbatim:** any `.sh` file (outside `tests/`, outside `mktemp` fixture
blocks) referencing a literal `.planning/workstreams`, `STATE.md`, `ROADMAP.md`, or
`REQUIREMENTS.md` path under `.planning/`; any path found that does not appear in
`workstream-planning-consumers.md` fails the lint.

has_frontmatter_key() { # <file> <key>

    NR == 1 && $0 ~ /^---[[:space:]]*$/   { in_fm = 1; next }
    in_fm && $0 ~ /^---[[:space:]]*$/     { exit }
    in_fm && $0 ~ "^" key ":[[:space:]]*" { found = 1; exit }

## Shared Patterns

### Exit-code convention (0/1/2/3/64), applies to every gate touched in this phase
**Source:** `plugin/conductor/scripts/check-divergence.sh` header, lines 44-52 (already quoted above).
**Apply to:** `vf_ws_enumerate` (new), `check-divergence.sh` (post-refactor),
`check-planning-consumers-registered.sh` (new, though it has no natural `3` SILENCE case — confirm
during planning), `check-planning-state.sh`, `detect-gsd-engine.sh`.
`0` = conforme/found · `1` = divergence/violation found · `2` = NON VÉRIFIABLE, never a disguised 0 ·
`3` = SILENCE (nothing to check, nominal for an unpartitioned repo) · `64` = usage error.

### Two-candidate sourcing of `workstream-policy.sh`
**Source:** `plugin/conductor/scripts/check-divergence.sh`, lines 94-102 (quoted above).

already the load-bearing integration point named in CONTEXT.md's `<code_context>` "Integration
Points". `planning-core` scripts (`check-planning-state.sh`, `detect-gsd-engine.sh`,
`discover-unintegrated-docs.sh`) live *next to* `workstream-policy.sh` already, so they source it
directly by `$(dirname "$0")/workstream-policy.sh` without the second candidate (see
`detect-gsd-engine.sh`'s own note at lines 74-76 on why it reimplements rather than sources across
modules today — `planning-core: requires: []`).

### Fixture discipline (never touch the real repo, never trust `diff`/`grep`)
**Source:** CONTEXT.md `<code_context>` "Discipline de fixture" section (quoted from `41.1-CONTEXT.md`
lines 216-218), reified in `test-check-divergence.sh` lines 31-54 and in
`.github/workflows/ci.yml`'s repeated `mktemp -d` + `git init -q` + `git add` + `git commit`
sequences (e.g. lines 585-615, 741-766, 881-895).
**Apply to:** every new test file and every new/extended CI step in this phase. `mktemp -d`, never
the real tree; `env -u GSD_WORKSTREAM -u VF_WORKSTREAM -u VF_WORKSTREAM_PLANNING_DIR` when isolation
from the invoking shell's environment matters; comparisons via `cmp`/`comm`/`cksum`, never `diff`;
sweeps via `awk`, never `grep` (both tools are proxied and silently lie on the author's machine, per
`scripts/check-machine-paths.sh` lines 41-43 and the CONTEXT.md note).
