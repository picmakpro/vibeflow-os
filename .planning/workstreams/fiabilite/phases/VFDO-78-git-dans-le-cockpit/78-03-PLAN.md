## Artifacts this phase produces

`plugin/cockpit/scripts/vf-cockpit-git-commandes.mjs` (neuf, sous 120 lignes) :
- `citer(s)` = `"'" + s.replace(/'/g, "'\\''") + "'"` (seule fonction de citation du module, utilisée par tous les constructeurs).
- `AFFICHAGE_REFUSE` = la classe de caractères de `nettoie` (vf-cockpit-arbres.mjs l.55), recopiée par ses points de code échappés dans le source : C0 (U+0000 à U+001F), DEL et C1 (U+007F à U+009F), U+2028, U+2029, bidi U+202A à U+202E et U+2066 à U+2069 (le source écrit des échappements, jamais le caractère lui-même).
- Constructeurs, chacun rend une chaîne ou `null` (entrée non chaîne, vide, plus de 200 caractères, ou qui répond à `AFFICHAGE_REFUSE`) :
  `cmdCd(chemin)` -> `cd -- '<chemin>'` ; `cmdSwitch(nom)` -> `git switch --end-of-options '<nom>'` ;
  `cmdDetacher(sha)` -> `git switch --detach --end-of-options <sha>` (sha au motif `^[0-9a-f]{7,64}$`, sinon null) ;
  `cmdBranchSupprimer(nom)` -> `git branch -d --end-of-options '<nom>'` ; `cmdShowStat(sha)` -> `git show --stat --end-of-options <sha>` ;
  `cmdStashShow(ref)` -> `git stash show --stat '<ref>'` (ref au motif `^stash@\{\d{1,4}\}$`, sinon null) ;
  `cmdCommitInitial()` -> `git commit -m "premier commit"` ; `cmdStatus()` -> `git status`.
- La forme exacte de `git branch -d` et de `git show` avec `--end-of-options` est confirmée par la suite (C2) ; si git 2.50 refuse
  `--end-of-options` sur l'une d'elles, le constructeur rend la forme `-- ` équivalente qui marche, et le SUMMARY le dit.
