## Registre d'extensions (contrat interne 74-04 -> 74-06 et 74-07)

`window.__vfFrise.enregistrer(nom, { rendre(ctx) })`, `nom` dans `curseur`, `encart`, `depot`, `cout`. La frise appelle `rendre(ctx)` de chaque module enregistré, dans cet ordre, après chaque rendu du corps de la frise ;
`ctx = { frise (normalisée par le modèle), modele, fenetre, lecture, depuis, jusqua, x(ms), curseurMs, emplacement (élément propre au module, dans l'ordre vertical d'UI-SPEC § 2), couche (div superposée aux pistes, Dépôt compris,
avec un `svg` `aria-hidden` pour les traits et une zone HTML pour les éléments focalisables), annoncer(texte), ouvrirFiche(id, origine) }`. Un module absent n'empêche rien ; un `rendre` qui lève est isolé (`try/catch`, la frise
continue). `poserCurseur(ms|null)` émet `vf-frise:curseur` sur `document`. Les emplacements `depot` (entre l'axe et les voies), `encart` et `cout` (sous les voies et la légende, dans cet ordre) existent vides dès ce plan.
