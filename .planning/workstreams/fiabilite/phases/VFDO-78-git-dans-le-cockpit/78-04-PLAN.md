## Artifacts this phase produces

- `plugin/cockpit/scripts/vf-cockpit-git-entete.mjs` (neuf, sous 90 lignes) : `enteteGit(lab, { sh = shBorne } = {})` ->
  `{ etat: 'ok'|'indisponible'|'absent', depot, branche, worktree, detache, sha7 }`. `rev-parse --path-format=absolute
  --git-common-dir` vide -> `absent`, `depot` = nom du dossier du lab. `depot` = nom du parent de `<commun>` quand `<commun>` se
  termine par `.git`, sinon nom de `<commun>` privé de `.git`. `worktree` = nom de `rev-parse --show-toplevel` quand il diffère du
  parent de `<commun>`, sinon `null`. `branche` = `symbolic-ref --quiet --short HEAD` ; vide -> `detache: true`, `sha7` =
