<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `--target <chemin>` (entrée utilisateur/CLI) -> TARGET_ROOT résolu -> tout le reste de l'engine | un chemin custom mal validé (vide, `/`, traversal `../..`) ne doit jamais devenir la racine d'un `rm -rf` de convergence ou de rollback |
| payload copié réécrit (.claude/ -> cible) -> fichiers posés sur disque | une substitution de motif trop large pourrait corrompre un fichier qui contient légitimement la CHAÎNE `.claude/` dans un contexte non-chemin (ex. un exemple de code dans une doc) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38-09 | Tampering | `--target` pointant vers un chemin vide/racine/traversal | high | mitigate | valider `--target` non-vide, résolu en absolu par `cd -P` (D-31-15), refuser `/` littéral et tout chemin qui remonterait au-dessus du repo pour le scope `local` |
| T-38-10 | Tampering | réécriture de motif `.claude/` trop large dans un fichier de contenu (doc/exemple) | medium | mitigate | substitution scoping sur les formes de chemin mesurées (relative/absolue/`${CLAUDE_PROJECT_DIR}`) plutôt qu'un remplacement texte naïf de la chaîne `.claude/` |
| T-38-11 | Information Disclosure | `.vibeflow-target` expose le chemin absolu de la cible sur disque | low | accept | information déjà dérivable de `TARGET_ROOT` lui-même, aucune exposition nouvelle |
| T-38-SC | Tampering | npm/pip/cargo installs | low | accept | aucun paquet externe installé par ce plan |
</threat_model>
