## Emplacement du gate — décision tranchée par ce plan

Le cadrage laissait ouvert l'emplacement du script (nouveau script contre extension d'un gate
existant). Tranché : **nouveau script, dans le module `conductor`**, à côté du kernel de mission.

Trois raisons. Le fichier d'invariants est un artefact de MISSION, et le kernel de mission
(verrou de driver, plan de bataille en DAG) vit dans ce module, qui est le seul module obligatoire —
donc le seul dont les scripts sont garantis présents sur tout lab. La §2 du fichier renvoie vers une
sous-commande du plan de bataille, elle-même livrée dans ce module. Enfin, le gabarit advisory de
référence vit dans un autre module : il est répliqué en STRUCTURE, ce qui n'exige aucune proximité
de dossier et évite une dépendance croisée entre un module obligatoire et un module optionnel.
