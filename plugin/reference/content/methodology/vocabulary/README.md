# Vocabulaire VibeFlow

> Le lexique generique de la methodologie. Ce qu'on dit, ce qu'on ne dit pas, et pourquoi.

## Comment lire ce dossier

Trois fichiers :

1. **`lexique.md`** — Glossaire complet des termes VibeFlow (concepts, registres, agents, rituels)
2. **`dire-ne-pas-dire.md`** — Mots a privilegier vs mots a eviter, avec justification
3. **`forks-mapping.md`** — Equivalences canoniques entre Core et forks usuels (DevFlow, BusinessFlow, etc.)

## Pourquoi un vocabulaire commun

Sans vocabulaire stable :
- Les memes concepts portent 5 noms differents → confusion en equipe
- Les agents ne se comprennent pas (le lead parle de "feature", le commercial de "initiative")
- La memoire devient illisible (mix de vocabulaire au fil des sprints)

Avec vocabulaire stable :
- Un seul langage par fork
- Les registres restent coherents dans la duree
- Les nouveaux arrivants montent en charge en quelques jours
