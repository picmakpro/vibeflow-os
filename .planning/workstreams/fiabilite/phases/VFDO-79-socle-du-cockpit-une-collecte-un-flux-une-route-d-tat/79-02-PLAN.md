## Règles de migration (tâches 2 à 4)

- **R1, source.** Juste après la ligne qui source `hygiene.sh` et appelle `vf_hyg_init` (trois formes dans les suites : `$(dirname "$0")`,
  `$HERE_T`, `$SCRIPTS/tests`), ajouter une ligne identique qui source `socle-serveur.sh` avec le même préfixe de chemin.
- **R2, remplacement.** Le lancement (sous-shell, `&`, redirections), la boucle d'attente de `server.json` et les lectures du port, du pid et du jeton
  dans `server.json` sont remplacés par un appel à `cockpit_lancer` suivi des affectations de la carte. Les noms de variables de la suite ne changent
  pas, aucune assertion n'est touchée. Les journaux que la suite lit gardent leur chemin par `COCKPIT_LOG` ; avant de décider qu'un journal n'est
  pas lu, compter (`rtk proxy grep -c`) ses occurrences dans la suite.
- **R3, environnement.** Chaque `NOM=valeur` qui précédait le lancement devient un argument `NOM=valeur`, ni plus ni moins (pas de défaut ajouté). Une
  sortie différente de `<dossier>/.vibeflow/cockpit` passe par `COCKPIT_SORTIE` ; la clé `terminal` attendue passe par `COCKPIT_PRET=terminal` avec
  l'option terminal ; les arguments de node par `COCKPIT_NODE_ARGS`.
- **R4, appel direct.** `cockpit_lancer` est appelé dans le shell courant, jamais dans `$(…)`, sinon `VF_PID` et les autres exports se perdent
  (les suites dont la fonction de démarrage est déjà appelée dans `$(…)` gardent le comportement d'aujourd'hui : serveur lancé et arrêté dans le
  sous-shell).
- **R5, échec.** Un retour non nul ne doit changer le comportement aval d'aucune suite : `VF_PORT=0`, `VF_PID` vide, comme les `|| echo 0` d'origine.
- **R6, retraits.** Les boucles d'attente de `server.json` et les tirages de port devenus inutiles sont retirés ; une fonction ou une variable
  locale (`libre`, par exemple) n'est retirée que si `rtk proxy grep -c` ne lui trouve plus aucun autre appel. Aucune autre pause fixe n'est réécrite.
- **R7, preuve par suite.** Avant de toucher une suite, la jouer une fois et noter son résultat (`Résultats` ou `TOTAL`) ; après, même résultat, code 0,
  aucune ligne `⊘`. Une suite qui saute faute de navigateur ne prouve rien : arrêter et le dire.
