  auteur, date, committer, dateCommit, message, tronque, fichiers: [{ chemin, ancien, plus, moins, binaire }], total, commandes }` ;
  appels : `rev-parse --show-object-format`, `rev-parse --verify --quiet --end-of-options <sha>^{commit}`,

  `rev-list --left-right --count refs/heads/<base>...<oid>` (et `refs/remotes/origin/<base>` si divergente).
