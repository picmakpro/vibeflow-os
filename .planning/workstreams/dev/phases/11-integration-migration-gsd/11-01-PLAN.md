# Plan 11-01 — Bascule mécanique (ensure-deps / detect-gsd-engine / build-gsd-index)

## But

Basculer les 3 scripts qui référencent le layout `get-shit-done` legacy sur `@opengsd/gsd-core`,
en dual-layout pendant la fenêtre de compat (labs pas encore migrés). Neutraliser le piège n°1
(`command -v gsd-sdk` dans `detect_gsd()` — le shim legacy resterait sur le PATH et empêcherait
gsd-core de jamais s'installer). Poser `detect_gsd_legacy()` (affichage seul, ADR-031) et la garde
Node ≥ 22.

Complète une partie des critères de succès 1 et 2 du ROADMAP (GSDM-04, GSDM-05 — la partie
« références docs » de GSDM-05 est couverte en 11-02/11-03, pas ici). Premier plan de la chaîne,
aucune dépendance amont.

**Ne régénère PAS `gsd-skills-index.md`** (fichier committé) — ce serait une release intermédiaire
cassant T14 avant que 11-03 ait posé le routage des nouvelles briques gsd-core (`gsd-onboard`,
`gsd-next`, `gsd-mempalace-*`). Voir `11-CONTEXT.md` §R-01.

## Exigences couvertes

GSDM-04 (ensure-deps non-interactif, idempotent, fallback manuel, `get-shit-done-cc` plus
référencé — partiel, le renommage du pin `PROJECT.md` est en 11-06). GSDM-05 (partiel — mécanique
des 2 scripts source, la régénération de l'index et les références docs sont en 11-03).
