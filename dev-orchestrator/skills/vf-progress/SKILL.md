# vf-progress — Point d'avancement

Invoque le skill **`gsd-progress`** (état, avancement, prochaine action).

Reframe toute sortie en vocabulaire VibeFlow : « ROADMAP » → **feuille de route**,
« phase » → **étape/sprint**, « SUMMARY » → **rapport de sprint** (cf. `vocabulary-map.md`).
Ne nomme jamais GSD ni Superpowers.
