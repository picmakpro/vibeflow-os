# Plan 11-01 — Bascule mécanique (ensure-deps / detect-gsd-engine / build-gsd-index)

## But

Basculer les 3 scripts qui référencent le layout `get-shit-done` legacy sur `@opengsd/gsd-core`,
en dual-layout pendant la fenêtre de compat (labs pas encore migrés). Neutraliser le piège n°1
(`command -v gsd-sdk` dans `detect_gsd()` — le shim legacy resterait sur le PATH et empêcherait
gsd-core de jamais s'installer). Poser `detect_gsd_legacy()` (affichage seul, ADR-031) et la garde
Node ≥ 22.

Complète une partie des critères de succès 1 et 2 du ROADMAP (GSDM-04, GSDM-05 — la partie
« références docs » de GSDM-05 est couverte en 11-02/11-03, pas ici). Premier plan de la chaîne,
aucune dépendance amont.

**Ne régénère PAS `gsd-skills-index.md`** (fichier committé) — ce serait une release intermédiaire
cassant T14 avant que 11-03 ait posé le routage des nouvelles briques gsd-core (`gsd-onboard`,
`gsd-next`, `gsd-mempalace-*`). Voir `11-CONTEXT.md` §R-01.

## Exigences couvertes

GSDM-04 (ensure-deps non-interactif, idempotent, fallback manuel, `get-shit-done-cc` plus
référencé — partiel, le renommage du pin `PROJECT.md` est en 11-06). GSDM-05 (partiel — mécanique

## Risques / points d'attention

- **Ne pas remplacer le test PATH par un autre test PATH.** Le piège n°1 n'est pas spécifique à
  `gsd-sdk` : n'importe quel `command -v gsd-core`/`gsd-tools`/`gsd_run` aurait le même défaut
  (shim legacy qui reste vrai). La détection doit rester strictement basée sur les fichiers
  VERSION.
- **`detect_gsd_legacy()` peut être vraie MÊME après une install gsd-core réussie** (coexistence
  non garantie propre, Phase 10) — c'est voulu : le nettoyage manuel doit être proposé tant que
  l'arbre mort existe, indépendamment du succès de la nouvelle install.
- **Ne pas régénérer `gsd-skills-index.md` dans ce plan** — c'est le risque R-01 documenté dans
  `11-CONTEXT.md`. Si la tentation apparaît en exécutant `build-gsd-index.sh` pour vérifier le
  fix WORKFLOWS_DIR, utiliser `VF_INDEX_OUT=$(mktemp)` (comme le fait déjà T1), jamais le chemin
  par défaut qui écrirait dans `references/`.
- **Portabilité BSD/GNU** pour l'extraction du major Node : ne pas utiliser `cut -d.` sur la
  sortie de `node --version` (le format `vX.Y.Z` a un préfixe `v` qui casse une comparaison
  numérique naïve) — préférer `node -e` qui retourne le major directement, comme spécifié.
- **`GSD_VERSION_FILE` (singulier) n'existe plus** dans `ensure-deps.sh` après ce plan — si un
  autre script du repo la référence (aucun trouvé à la lecture de ce cadrage), le grep de
  vérification `grep -c 'get-shit-done-cc'` ne le détecterait pas ; vérifier aussi
  `grep -rn 'GSD_VERSION_FILE[^_]' plugin/` → 0 résultat après ce plan.
