<objective>
Clore la phase par ce qui rend les quatre livrables **atteignables** : le câblage du gate
anti-drift chez son consommateur, la clôture de distribution (triades de module, compteurs
re-dérivés, gate de synchro vert), et le verdict humain sur ce que le gate trouve réellement.

Purpose : la Phase 28 a établi le motif que cette phase ne doit surtout pas rejouer — un mécanisme
armé dans le dépôt qui n'atteint jamais le poste de l'utilisateur parce que personne n'a posé le
maillon de distribution. Un gate écrit et testé mais qu'aucun consommateur n'invoque, ou dont le
module n'est pas bumpé, est exactement ce cas de figure. Ce plan ferme les deux bouts.

Le câblage se fait sous une contrainte dure : les deux fichiers les plus intuitifs pour l'accueillir
sont **au plafond de densité ADR-029, à 250/250 lignes, marge zéro**. Le câblage se paie donc en
retrait équivalent, pris sur du texte d'exemple — jamais sur un signal de la grille.

La phase se termine sur un **checkpoint humain** : le gate tourne pour de vrai sur ce dépôt, ses
findings sont présentés, et **aucun** n'est corrigé en exécution. C'est la lettre d'ADR-031, et
c'est aussi la seule manière honnête de savoir si le gate est utile ou bavard **avant** de le
distribuer.

Output : le validator câblé, 4 triades bumpées, 2 compteurs re-dérivés, un verdict humain consigné.
</objective>
