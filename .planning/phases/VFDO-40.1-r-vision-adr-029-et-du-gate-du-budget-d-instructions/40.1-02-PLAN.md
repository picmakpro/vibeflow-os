  <action>
`tools/check-phase-invariants.sh [--base <sha>] [--min-agents N] [--gate <script>] [--root <dir>]`
(défauts : `4e7c8e4`, 3, `plugin/conductor/scripts/check-instruction-budget.sh`, toplevel git).
Commits de phase = commits de `<base>..HEAD` au sujet `^[a-z]+\(40\.1`. Parcours en awk, jamais
`grep`, chaque sortie de `git` capturée dans un fichier avant lecture (aucun git en pipeline).
- **I1 :** commits de phase touchant `.planning/instruction-budget-baselines.tsv` ≥ 1. Pour chacun,
  les lignes de données à `C^` et à `C` doivent être identiques (`cmp`).
- **I2 :** pour chaque commit de phase touchant `plugin/*/agents/*.md` ou `plugin/*/AGENT.md`, lire
  `git diff -U0 C^ C` sur ces chemins. Ignorer les en-têtes `diff --git`, `--- `, `+++ ` et `@@`.
  Chaque ligne retirée passe par la fonction awk `swap` : remplacer l'ancienne valeur par 300
  seulement si le caractère précédent n'est ni chiffre ni point et le suivant n'est pas un chiffre.
  La ligne retirée ainsi transformée doit égaler la ligne ajoutée de même rang dans le fichier.
  Par fichier, ajoutées = retirées. Nombre de fichiers distincts comparés ≥ `--min-agents`.
- **I3 :** lancer le gate (`--path <root>`), capturer sa sortie. Chaque ligne `plugin/…` doit avoir
  LIGNES = BL-LIGNES, INSTR = BL-INSTR, un verdict sans `DEPASSEMENT` ni `LIGNES-EN-HAUSSE`, et le
  nombre de lignes du rapport doit égaler le nombre de lignes de données de la baseline (> 0).
- **I4 :** aucun commit de phase ne touche `VERSION`, `plugin/.claude-plugin/`,
  `plugin/.codex-plugin/` ou `.claude-plugin/`.
Trace à trois champs par écart. Bilan `INVARIANTS : I1=<ok|ko> I2=<…> (fichiers=<n>) I3=<…> I4=<…>`.
rc 0 si tout tient, 1 si un invariant échoue, 2 si ce n'est pas un dépôt git ou si le gate est
introuvable.

`tools/test-check-phase-invariants.sh` monte un dépôt jetable. Il y copie le gate réel du dépôt

`plugin/c/agents/x.md` (chacun avec une ligne `agents ≤ 250 lignes` et une ligne neutre), la
sentinelle et une baseline exacte mesurée par le gate, puis un commit neutre servant de base.
Cas :
- V1 : commit `docs(40.1-99): …` remplaçant la valeur par 300 dans les trois agents, plus un commit
  `docs(40.1-99): …` modifiant seulement un commentaire de la baseline → rc 0, `fichiers=3`.
- V2 : la ligne retirée réécrite autrement (mot ajouté) → rc 1, I2 ko.
- V3 : une ligne ajoutée en plus dans un agent → rc 1.
- V4 : un commit de phase qui change une ligne de données de la baseline → rc 1, I1 ko.
- V5 : aucun commit de phase → rc 1 (I1 et I2 à vide sont rouges).
- V6 : un commit HORS phase (`fix(hotfix): …`) réécrit librement un agent, en plus de V1 → rc 0

- V7 : un commit de phase touche `VERSION` → rc 1, I4 ko.
- V8 : une ligne d'agent contenant `2500` inchangé à côté du remplacement → rc 0 (frontière de

- V9 : `--min-agents 4` sur V1 → rc 1.
