- `CLOTURE` = l'expression de F7, `/(?:—|\()\s*(?:complete|completed|close)\s+(\d{4}-\d{2}-\d{2})/i` ;
  `INSCRIPTION` = `/inscrite\s+(\d{4}-\d{2}-\d{2})/i` (gelées).
- `dates(line)` → `{ cloture: 'AAAA-MM-JJ' | null, inscription: 'AAAA-MM-JJ' | null }` ; première occurrence ancrée ;
  une date de calendrier invalide donne `null`.
- `burnup({ jalon, phases, pct })` où `phases` = `[{ n, nom, line, etat }]` dans l'ordre du ROADMAP et `pct` la fonction
  injectée → `null` si `jalon` manque ou si `phases` est vide ; sinon

  - `clos` = phases à l'état `fait` ; `total` = nombre de phases ; `pct` = `pct(clos, total)` ;
  - date d'entrée d'une phase = sa date d'inscription, ramenée à sa date de clôture si celle-ci est plus ancienne ; sans
    inscription : `ouverture` ;
  - `ouverture` = la plus ancienne des dates d'inscription et des dates de clôture des phases `fait` ; `null` s'il n'y en a
    aucune (alors `serie` est vide) ;
  - `serie` : un point par date distincte où le périmètre ou les clôtures changent, croissante, le premier à `ouverture` ;
    `perimetre` et `clos` cumulés ; `closes` = numéros des phases closes ce jour-là ; le dernier `perimetre` vaut `total` ;
  - une date de clôture d'une phase qui n'est pas `fait` est ignorée ; une phase `fait` sans date de clôture va dans
    `closesSansDate`.
