  `{ schema, etat: 'ok'|'vide'|'indisponible'|'absent', entete, base: { nom, locale, distante, divergent },
  worktrees: [{ nom, chemin, branche, detache, ici, principal, commande }],
  rangees: [{ h, h7, p, at, an, s, col, entrants, sortants, largeur, ouvertBas, fusion, racine, teinte, refs: [{ type, nom, courante, worktree, commande }] }],
  couloirsMax, replies, horsFenetre: [{ nom, h7, avance, retard }], mergees: [{ nom, commande }],
  tags: [{ nom, h7, at }], stash: [{ ref, h7, at, message, branche, commande }],
  auteurs: [{ nom, commits, dernier }], parBranche: [{ nom, avance, dernier }],
  bornes: { base, nonMergees, tronque }, commandes: { vide, diagnostic } }`.
  Étapes, sous `avecEcheance(BORNES.echeanceMs, …)` : `enteteGit` (absent -> `{ schema, etat:'absent', entete }`) ;
  `brancheBase` (vf-cockpit-arbres.mjs) ; `lancerGit` `for-each-ref` sur `refs/heads refs/remotes refs/tags` (format à `%00`, lu par
  `lireRefs`) ; `worktree list --porcelain -z` (`lireWorktrees`) ; `log --topo-order -z --format=<FORMAT_JOURNAL> -n 500 <base> <HEAD
  des worktrees>` ; `log … -n 500 <refs non mergées> --not <base>` ; `ordonner`, `placer`, `etiquettes` ;
  `stash list -z --format=%gd%x00%H%x00%ct%x00%gs -n 50`. Teinte 0 pour les commits de la chaîne des premiers parents de la base.
  Toute chaîne servie passe par `nettoie(s, BORNES.nom)` ; `refs` d'une rangée bornées à 12 (le reste compté pour le « +N » de l'UI).
- `routeGit(req, res, url, { root, json })` -> `true` si la route est traitée : méthode autre que GET -> 405 ;
  `/api/vf/git` -> `json(res, 200, lireGit(root))` ; `/api/vf/git/entete` -> `{ schema: 'vibeflow/cockpit-git-entete@1', ...enteteGit(root) }` ;
  autre `/api/vf/git/*` -> 404 ; exception -> `json(res, 200, { schema, etat: 'indisponible' })`.
- `vf-cockpit-server.mjs` : import de `routeGit` et une ligne dans `route()` avant le 404 final ; l'en-tête du fichier liste les
  deux routes.
- `vf-cockpit-interface.json` : `schemas['vibeflow/cockpit-git@1']` (`requis`, `etats`, `rangee.requis`, `interdits` = la liste
  commune) et `schemas['vibeflow/cockpit-git-entete@1']`.
