**Security-critical resolution cascade — MUST port, not skip** (`plugin/conductor/scripts/dag.sh:149-187`,
Python embedded in this bash file, but the invariant is language-agnostic and load-bearing):
```python
def resolve_gsd_tools_cmd():
    """Cascade de resolution de la CLI amont (D-07), dans cet ordre : variable d'environnement
    GSD_TOOLS si elle pointe un fichier existant -> executable `gsd-tools` sur le PATH -> sous
    CLAUDE_CONFIG_DIR puis sous ~/.claude. ...
    AUCUN candidat cwd/repo-relatif (ex. l'ancien `<cwd>/gsd-core/bin/gsd-tools.cjs`, retire) :
    un tel candidat resout un executable a un chemin RELATIF AU REPERTOIRE DE TRAVAIL COURANT puis
    l'invoque via `node` sans aucune verification d'ancrage. PoC rejoue en audit : un simple
    fichier tracke (`gsd-core/bin/gsd-tools.cjs` a la racine d'une branche ou d'une PR malveillante)
    suffit a faire executer du code arbitraire ..."""
    resolved = None
    env_tools = os.environ.get("GSD_TOOLS", "")
    if env_tools and os.path.isfile(env_tools):
        resolved = env_tools
    if resolved is None:
        resolved = shutil.which("gsd-tools")
    if resolved is None:
        config_dir = os.environ.get("CLAUDE_CONFIG_DIR") or os.path.expanduser("~/.claude")
        cand = os.path.join(config_dir, "gsd-core", "bin", "gsd-tools.cjs")
        if os.path.isfile(cand):
            resolved = cand
    if resolved is None:
        return None
    if resolved.endswith(".cjs"):
        node_bin = shutil.which("node")
        return [node_bin, resolved] if node_bin else None
    return [resolved]
```
**This is the single most load-bearing excerpt in this pattern map.** RESEARCH.md's own proposed
skeleton (`GSD_TOOLS="${GSD_TOOLS:-$HOME/.claude/gsd-core/bin/gsd-tools.cjs}"`) is a **regression**
against this already-fixed vulnerability class if copied literally without the `PATH`/`CLAUDE_CONFIG_DIR`
cascade — it silently degrades to a fixed `$HOME` guess (which is *safe*, since it drops the
cwd-relative candidate entirely) but does not honor an explicit `GSD_TOOLS` override or a
`CLAUDE_CONFIG_DIR`-scoped install the way the rest of `conductor` does. Port the three-tier order
(`GSD_TOOLS` env → `PATH` → `CLAUDE_CONFIG_DIR`|`~/.claude`/gsd-core/bin/gsd-tools.cjs) into bash,
and **never add a cwd- or repo-relative candidate path** — that is the exact vulnerability this
function was rewritten to close (see the docstring's PoC description).
