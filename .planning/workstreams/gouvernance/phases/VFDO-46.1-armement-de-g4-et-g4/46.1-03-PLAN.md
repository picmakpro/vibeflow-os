Script `plugin/planning-core/scripts/verifier-releve.sh` (lanceur bash sur le patron de
`rejeu-reel.sh` l. 36-60 : `set -uo pipefail`, `--help` = en-tête `# `, résolution de Python, cœur
`-I -S -` par heredoc ; le relevé est un ARGUMENT, jamais stdin).
Usage : `verifier-releve.sh --etape=<5|6> [--lab=<lab affiché>]… <relevé>`. Codes : 0 armable,
1 non armable, 64 usage (étape absente ou autre que 5/6, option inconnue, zéro ou deux relevés).
Sortie : une ligne `RELEVE-ECART <règle> : <détail>` par écart, puis UNE dernière ligne
`RELEVE-VERDICT armable etape=<n> labs=<k> gates=<G3,G4[,G4P]>` (code 0) ou
`RELEVE-VERDICT non-armable etape=<n> ecarts=<m>` (code 1).
Lecture : `os.open(…, O_RDONLY | O_NOFOLLOW)`, `fstat` régulier, borne d'octets (constante
`BORNE_RELEVE`, 64 Mio), UTF-8 strict ; un échec rend l'écart `lecture`.
Règles, UNE ligne `if <condition>:  # releve-<règle>` chacune, dont le corps appelle l'écart
(c'est ce que les mutants neutralisent) : `lecture`, `vide`, `etape-absente`, `etape-malformee`,
`etape-doublon`, `etape-autre` (une ligne `REJEU-ETAPE-<m>` avec m ≠ n), `faux-refus`,
`faux-accept`, `commit-absent`, `commit-malforme`, `commit-doublon`, `labs-absents`,
`empreinte-absente`, `empreinte-doublon`, `empreinte-divergente`, `mesure-vide`,
`couverture-absente`, `couverture-malformee` (dont `plancher=0`), `couverture-doublon`,
`couverture-insuffisante`, `chemin-machine` (`/Users/` ou `/home/` dans une ligne).
Grammaire exacte (lignes entières, `\r` final = malformée) : `^REJEU-ETAPE-([0-9]+) faux-refus=([0-9]+) faux-accept=([0-9]+) refus-conforme-modele=([0-9]+)$` ;
`^COMMIT-REJOUE [0-9a-f]{40}$` ; `^EMPREINTE-ARBRE-(IDENTIQUE|DIVERGENTE) (.+)$` (ne JAMAIS
confondre avec `EMPREINTE-IDENTIQUE`, émise par rejeu-gates.sh sur son périmètre restreint, qui
n'est pas lue) ; `^MESURE-VIDE (.+)$` ; `^COUVERTURE-REJEU (G3|G4|G4P) n=([0-9]+) plancher=([0-9]+)$` ;
ligne de table : au moins six champs séparés par ` | `, premier champ `^[A-Z][A-Z0-9]*$` (les lignes
de tableau Markdown, qui commencent par `|`, ne comptent pas). Les lignes `COMPTE …` sont
informatives (jamais lues pour décider). Le détail d'un écart nomme la règle, le numéro de ligne et
le jeton en cause, jamais la ligne fautive entière (un écart `chemin-machine` ne recopie pas le
chemin : la sortie du script est reproduite telle quelle dans les relevés versionnés). Les lignes
`RELEVE-ECART` / `RELEVE-VERDICT` qu'un relevé porte déjà (décision reproduite) sont inertes : aucune
règle ne les lit.
