## Contrainte d'environnement (lire avant tout)

Cette session tourne dans un worktree git isolé (cwd ci-dessus). Un hook global (rtk) réécrit `git …` et `gh …` en `rtk git …` / `rtk gh …`, et la garde d'isolation du worktree REFUSE alors la commande (« Refusing to run it — a worktree-isolated session's git operations must target its own worktree »). Toute commande git ou gh doit donc être écrite avec un antislash initial — `\git add …`, `\git commit …`, `\git status …`, `\git diff …`, `\git log …`, `\gh …` — sans `cd`, depuis le cwd courant. `git rev-parse`, `git checkout`, `git switch`, `git ls-files` ne sont pas réécrits mais l'antislash est sans effet : l'utiliser partout. Ne jamais tenter un `cd` vers l'arbre principal du dépôt (verrouillé par une autre session). Les tests bash du repo (`bash plugin/_internal/tests/test-vibeflow-update.sh …`) lancent git en interne depuis des dossiers temporaires : c'est un processus enfant, non réécrit, pas concerné.
