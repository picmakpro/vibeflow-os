## Artifacts this phase produces

Contrat `#vf-budget@1` (forme exacte, fixée par ce plan ; P77-D-03 et « Claude's Discretion » de 77-CONTEXT) :

- Sortie standard en UTF-8, fins de ligne LF, champs séparés par UNE tabulation, sans guillemets. Aucun champ ne porte
  de tabulation ni de saut de ligne (un chemin qui en porterait est émis `-`).
- Ligne 1 : `#vf-budget@1`, tabulation, nom du gate : `check-method-budget` ou `check-instruction-budget`.
- Lignes suivantes, six champs : `type`, `chemin`, `valeur`, `budget`, `unite`, `verdict`.
- Types et unités, liste fermée :
  - `check-method-budget` : `state` (Ko), `state-prose` (lignes), `backlog-ouverts` (sujets), `backlog-entree` (lignes),
    `backlog-clos` (sujets, budget 0), `roadmap` (Ko), `memory-index` (lignes), `worktrees` (worktrees) ;
  - `check-instruction-budget` : `agent` (lignes), `skill` (lignes), `socle` (jetons), `socle-baseline` (jetons).
- Verdicts, liste fermée : `OK`, `AVERTISSEMENT`, `DEPASSE`, `NON-VERIFIABLE`, `NON-APPLICABLE` ; pour `socle-baseline`
  seulement : `EGALE`, `AU-DESSUS`, `EN-DESSOUS` (relation de la mesure du socle à sa ligne de baseline, décidée par le
  gate dans la comparaison qu'il fait déjà).
- `valeur` : entier décimal positif ou nul ; `-` si et seulement si le verdict est `NON-VERIFIABLE` ou `NON-APPLICABLE`.
- `budget` : entier décimal, valeur EFFECTIVE (variables `VF_*` comprises) ; `-` seulement pour `socle-baseline`.
- `chemin` : relatif à `--root` / `--path` ; `.` désigne la racine ; `-` = sans objet ou hors de la racine. Jamais un
  champ qui commence par `/` ou `~`, jamais un segment `..`.
- Verdict d'une ligne d'agent : celui des LIGNES seules, décidé par les comparaisons que le gate fait déjà
  (`DEPASSE` au-delà de `VF_BUDGET_LINE_CAP`, `AVERTISSEMENT` dès `VF_BUDGET_LINE_WARN_FROM`, `OK` sinon, `NON-VERIFIABLE`
  pour un fichier illisible ou imparsable). Le ratchet des instructions n'est pas une jauge (P77-D-06 : aucun autre budget).
- Verdict du socle : `OK` ; `DEPASSE` pour `DEPASSEMENT-BOOTSTRAP` et `AU-DESSUS-PLAFOND-ADR029` ; `NON-APPLICABLE` ;
  `NON-VERIFIABLE`. La ligne `socle-baseline` n'est émise que si le gate a lu une ligne de baseline.
- Cas particuliers : aucun STATE sous la racine → une ligne `state` `-` `-` `<budget>` `Ko` `NON-APPLICABLE` ; lab sans
  corpus de densité → trois lignes `agent`, `skill`, `socle` en `NON-APPLICABLE`, code 2 gardé ; fichier illisible →
  ligne du type en `NON-VERIFIABLE`.
- Codes de retour du mode TSV : ceux du mode texte pour les mêmes options (la fin de script n'est pas touchée) ; 64 pour
  un refus d'usage.

Correspondance avec le vocabulaire de `77-UI-SPEC.md` (« jeton du gate, fixé par le plan 77-01 ») : `OK` → « Dans le
budget » ; `AVERTISSEMENT` → « À surveiller » ; `DEPASSE` → « Dépassé » ; `NON-APPLICABLE` → « Non applicable dans ce
lab » ; `NON-VERIFIABLE` → « Indisponible ». La table de l'UI-SPEC listait les jetons texte du gate ; ce plan les
remplace par cette liste fermée, ce que l'UI-SPEC prévoyait.
