<objective>

committées entre branches (ACTV-05, ACTV-06, ACTV-10 pour la source « deux branches », ACTV-04 pour la tâche, le cache
et le mono-vol). Ce plan ne branche aucune route (75-05) et ne touche aucune page.

selon l'aide commune de la 79 (plan 79-02, `plugin/cockpit/scripts/tests/socle-serveur.sh`) si elle lance un serveur,
ce qui n'est pas le cas ici (modules importés en `node`).

Output: trois modules (chacun <= 300 lignes), une suite, une trace de rouge.
</objective>
