    premier argument, options exactement `{ phase, ws, fichier, couper }` ; `phase` = identifiant de nœud de la phase du registre
    (`ph-<N>` ou `ph-<N>@<ws>`), reçu de l'appelant, jamais calculé par le module ; rend `[{ id, cle: '<ID>:<phase>', nue, titre,
    adr: [ids], amendee, ligne }]` ; motif constant
    `DEF = /^[-*+] \*\*((?:[A-Z][A-Z0-9.]*-)*D-\d+[a-z]?(?:bis)?)/` : motif de la recherche dont la classe de préfixe admet le
    point, comme `citations()` et le `--grep` git (la classe sans point manquait les 36 définitions `- **P71.5-D-nn` du corpus réel,
    relevé du plan-checker, révision 1) ; une seule constante de classe de préfixe partagée par `DEF` et `citations()` (par ex.
    `PREFIXE = '[A-Z][A-Z0-9.]*'`), pour que définitions et citations ne puissent plus diverger ; `titre` = reste de la ligne sans
    gras ni accents graves, coupé au mot à 80 caractères (`clipMot` de `vf-cockpit-planning.mjs` n'est pas importé : la coupe est
    reçue en paramètre `couper`, pour garder le module sans dépendance de lecture) ; `nue` = identifiant sans préfixe de registre.
  - `citations(message)` → `{ adr: [ids], decisions: [ids préfixés] }` (motifs constants `ADR-\d{3}` et
    `(?:[A-Z][A-Z0-9.]*-)+D-\d+[a-z]?(?:bis)?` en mot entier ; une citation nue `D-04` n'est jamais retenue).
  - `relier({ adrs, definitions, commits })` → `{ parAdr: Map(id → { decisions: [cles], commits: [h7] }), parDecision:
    Map(cle → { adr: [ids], commits: [h7] }), adrSansSection: [ids] }` ; `cle` de décision = `<ID>:<ph-id>` (identifiant de nœud de
    la phase du registre), nue comprise ; une nue n'a jamais de commit.

  - `commitsCitants(root, sha, { fin, max = BORNES_TRACE.commits })` → `{ commits: [{ h7, jour, sujet, adr, decisions }], tronque,
    absent }` par `log -E --grep=ADR-[0-9]{3}|[A-Z][A-Z0-9.]*-D-[0-9]+ --max-count=<max> --format=%H%x00%ad%x00%s%x00%B%x1e
