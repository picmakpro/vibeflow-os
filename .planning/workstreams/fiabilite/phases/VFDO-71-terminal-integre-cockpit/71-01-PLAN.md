## Interface (contrat figé par ce plan, consommé par 71-02 à 71-10)

- **Crochets de `serve.mjs` (P25)** : `preparerTerminal({ here, root, jetons, plateforme = process.platform })`. `jetons` est une fonction
  qui rend les jetons de P (`[token, VF?.ptoken]`) au moment de l'appel. Rendu : `actif` (booléen), `indisponible` (booléen),
  `injection()` (chaîne ajoutée à `inject`), `frameSrc()` (`'; frame-src http://127.0.0.1:<Q>'` ou `''`), `occupe()`, `routeP(req, res)`,
  `demarrer(portP)`. Messages du module préfixés « vf-cockpit (terminal) : », en français, nommant des états, jamais des données.
- **Origine de Q** : `http://127.0.0.1:<Q>`, port éphémère. `server.json` gagne la clé `terminal: { url }` (0600), jamais un secret.
- **Routes de Q** (toute autre : 404 ; méthode non prévue : 405) :
  `GET /` (`?theme=dark|light`) page du terminal, seule route admise sans Origin ;
  `POST /amorce` (en-tête `X-VF-Amorce`, corps vide) -> 200 `{ "secret": "<64 hex>" }` ;
  `GET /flux` (en-têtes `X-VF-Terminal`, `X-VF-Onglet`, optionnel `X-VF-Taille: <lignes>x<colonnes>`) -> 200 `application/octet-stream`, octets bruts ;
  `POST /entree` (corps : octets bruts) -> 204 ; `POST /taille` (corps : `<lignes> <colonnes>`) -> 204 ;
  `GET /etat` -> `{ "session": "absente|vivante|detachee|terminee", "code": n|null, "signal": n|null }`.
  Refus : 403 (Host, Origin), 401 (secret), 409 (autre onglet, 71-04), 410 (aucune session vivante, 71-04), 413 (corps trop grand, 71-02).
  `/flux`, `/entree` et `/taille` portent tous `X-VF-Onglet` ; la route le passe tel quel à la session.
- **Côté P** : `GET /api/vf/terminal` (sous jeton de P, en-tête `x-vf-cockpit-token` après renommage) -> `{ etat, port? }` (P71-PL-05).
- **Session** : `creerSessions({ engineDir, lab, jetons })` ; `attacher(req, res, { onglet, lignes, colonnes })` lance l'assistant à la
  première attache seulement et rend `200` (réponse prise en charge), `400` ou `409` ; `ecrire(octets, onglet)` et `redimensionner(l, c, onglet)`
  rendent `204`, `409` (autre onglet) ou `410` (aucune session) ; `etat()`, `occupe()`, `arreterTout()`. La route écrit le statut rendu.
  La ligne de lancement de l'assistant (`'-I'`, chemin, arguments, `cwd`, `env`) est l'ancre des mutants M-SANS-I et M-CWD de 71-03 :
  71-04 ne la réécrit pas.
- **Assistant PTY** : `python3 -I <VF_COCKPIT_ENGINE_DIR>/terminal/vf-cockpit-pty.py <lignes> <colonnes> <shell>`, `cwd` = `realpath(lab)`,
  environnement = `envShell(...)` ; fd 0 entrée, fd 1 sortie, fd 2 état (`FIN <code>`, `SIG <n>`), fd 3 contrôle (`R <l> <c>`) ; EOF du fd 0
  ou SIGTERM : SIGHUP au groupe, fermeture du maître, au plus 3 s, SIGKILL du groupe (71-03), sortie.
- **Page Q** : `preparerPage({ engineDir })` lève une erreur en français si le vendor manque ou est altéré (71-05) ; `pageTerminal({ theme,
  origineP })` rend `{ html, csp }`. Scripts inlinés sans attribut (71-05) : `xterm.js`, `addon-fit.js`, `(vueTerminal)(cfg)`, `(clientTerminal)(cfg)`.
- **Lanceur (71-10)** : `vf-cockpit.mjs open --terminal` écrit l'amorçage (O3), passe `--terminal --no-open` au serveur, attend `terminal.url`
  dans `server.json`, ouvre `<url>/#t=<amorçage>` (sauf `--no-open`).
- **Messages Q -> P** (liste fermée, P71-D-18) : `ready`, `etat:connecte`, `etat:reconnexion`, `etat:termine`, `etat:refuse`, `etat:expire`,
  `etat:arrete`, `toggle`.

  `read -a` ; listes dans des tableaux. Les commandes `<automated>` tournent aussi sous zsh : aucune boucle `for c in $var` ; une commande

- Processus de test tués par PID enregistré (`vf_hyg_stop`), jamais par motif : ni `pkill -f`, ni `awk` sur `ps` (incident du 2026-11-02).
  Descendants relevés par `pgrep -P <pid>` (par parent, jamais par motif) ou par fichier de PID écrit par le shell de test.
- Aucun tube `| tail` ou `| head` sur une suite : sortie redirigée dans `${TMPDIR:-/tmp}/71-NN-<nom>.out`, puis lue.

- Chrome headless Linux n'a pas de pointeur (`pointer: none`) : gestes par `Input.dispatchMouseEvent`/`dispatchKeyEvent`, aucune
  condition sur `hover` ni `pointer: fine`. Sans Chrome, une suite navigateur l'annonce par sa ligne de saut ; les `<verify>` des plans
  exigent l'absence de cette ligne.
- Assistant et témoins Python lancés `python3 -I` ; aucun `python3 -c` dans un fichier livré.
- Aucun chemin absolu de machine dans un fichier versionné (`scripts/check-machine-paths.sh`).
- Sous `rtk`, préfixer par `rtk proxy` tout comptage dont le résultat décide (sortie vide comptée 1 ligne).
