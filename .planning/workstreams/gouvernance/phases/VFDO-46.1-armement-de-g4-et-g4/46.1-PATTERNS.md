## Pattern Assignments

### P-01. `HOOK` · `evaluer_g4` : exemption étroite de la réécriture (ARMG-01)

**Analog :** `evaluer_g4`, `HOOK:1914-1956` (point d'insertion exact : entre la ligne 1925 et la ligne 1926).

**Entrée et forme d'unité** (`HOOK:1914-1927`) :
```python
def evaluer_g4(contexte):
    racine = contexte["racine"]  # g4-sonde
    if contexte["outil"] not in OUTILS_ECRITURE or not contexte["ecrit"]:
        return []
    composants = composants_nfc(contexte["ecrit"], racine)
    unite = unite_de_fichier(composants, "SUMMARY.md")  # g4-forme
    if unite is None:
        return []
    import hashlib
    chemin_rel = "/".join(composants)
    dossier = os.path.join(racine, *unite)
    verdict = os.path.join(dossier, "VERDICT.md")
    if not os.path.lexists(verdict):  # g4-verdict-absent
        return [Verdict("G4", chemin_rel, "aucun VERDICT.md : faites juger l'unité (poser-verdict.sh)")]
```

**Prédicat « fichier régulier »** à réutiliser tel quel (`HOOK:482-487`) : `est_fichier_regulier(chemin)` = `lstat` + `S_ISREG`, jamais de suivi de lien. « Absence au sens `lexists` » (P461-D-01) est déjà écrite à la ligne 1927 : `os.path.lexists(verdict)`. Même forme pour `CLOTURE.md`.

**Forme à poser** (marqueur `# g4-reecriture`, une seule ligne portant ce motif, convention de `make_hook_mutant`, `TESTS/test-cloture-gates.sh:360-390`) : `si est_fichier_regulier(contexte["ecrit"]) et non lexists(VERDICT.md) et non lexists(CLOTURE.md) -> return []`, **avant** `g4-verdict-absent`.

**Pièges mesurés dans le code, pas dans le CONTEXT :**
1. `composants_nfc` (`HOOK:471-478`) rend le chemin **résolu physiquement** (`os.path.realpath`) : un `SUMMARY.md` en lien est déjà remplacé par sa cible. Le test « ni lien » du CONTEXT doit donc porter sur `contexte["ecrit"]` (le chemin tel qu'écrit, dernier composant non résolu — `cible_de`, `HOOK:230-284`, ne le résout pas), **jamais** sur `os.path.join(dossier, "SUMMARY.md")` ni sur un chemin rebâti depuis `composants`.
2. Famille de banc « SUMMARY.md existant en lien → doit-refuser » : le lien doit viser un `SUMMARY.md` d'une **autre unité de forme modèle** (`01-lien/SUMMARY.md -> ../02-cible/SUMMARY.md`), sinon le `realpath` sort de la forme et le hook se tait (`unite is None` → `[]`, ce serait `silence`, pas `doit-refuser`). Un lien pendant vers un nom non conforme est un **jumeau négatif** distinct.
3. `unite_de_fichier` compare le nom en `casefold` (`HOOK:1806`) : sur un disque sensible à la casse, écrire `summary.md` **crée** un autre fichier ; l'exemption ne doit s'appliquer que si le fichier réellement écrit existe (lstat du chemin écrit), pas si `SUMMARY.md` existe à côté.
4. Hors périmètre de l'exemption : `Edit` d'un fichier absent échoue dans le harnais ; l'exemption couvre `Write`, `Edit` et `NotebookEdit` ensemble (`OUTILS_ECRITURE`, `HOOK:1211`).

**Texte à amender dans le même lot (REF et en-tête)** : le commentaire de l'en-tête de G4, `HOOK:1879-1887` (« retoucher le SUMMARY.md d'une unité close reste permis tant que le verdict tient »), et `REF:1241-1259` (même phrase, ligne 1248), plus la limite (bp) `REF:1056`.
