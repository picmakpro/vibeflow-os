  traduction : `OK`→`ok`, `AVERTISSEMENT`→`surveiller`, `DEPASSE`→`depasse`, `NON-APPLICABLE`→`na`,
  `NON-VERIFIABLE`→`indispo` ; tout autre jeton → `format`.

- `lireTsv(texte, gate)` → `{ ok: false, cause: 'format' }` si la première ligne n'est pas exactement `ENTETE` + tabulation
  + `gate`, sinon `{ ok: true, lignes, tronque }` ; lignes bornées à 2 000, champs à 512 caractères ; une ligne est
  `format` si elle n'a pas six champs, si son unité ne correspond pas à son type, si `valeur`/`budget` ne sont pas des

  de lecteur : son chemin est alors servi `null` et jamais recopié.
- `etatSource(lancement, gate)` → `{ etat: 'ok'|'non-applicable'|'indisponible', cause, lignes }` : script non résolu ou
  binaire absent → `absent` ; `delai` ou `echeance` → `delai` ; code 64 → `ancien` ; en-tête absent ou de version inconnue
  → `format` ; sortie tronquée → `echec` ; gate de densité en code 2 avec au moins une ligne `NON-APPLICABLE` →
  `non-applicable` ; sinon `ok` (les lignes font foi).
- `assembler({ methode, densite, at })` → l'objet servi :
  `{ schema, at, sources: { methode: { etat, cause }, densite: { etat, cause } }, jauges: [ … onze, ordre de TYPES … ] }`,
  chaque jauge `{ type, groupe, unite, verdict, cause, mesures: [{ chemin, valeur, budget, verdict }], tronque, baseline }`,
  `baseline` = `{ valeur, relation: 'egale'|'au-dessus'|'en-dessous' }` pour `socle` si le gate l'a émise, sinon `null`.
  Verdict d'une jauge : `indispo` (cause de la source) si sa source est indisponible ; `na` si sa source est non
  applicable ou si le gate n'a émis aucune mesure de ce type ; sinon celui de `mesures[0]`. Ordre des mesures : `depasse`,
  `surveiller`, `indispo`, `format`, `ok`, puis rapport valeur/budget décroissant, puis chemin ; au plus 200 (`tronque`).
  Aucune valeur n'est jamais remplacée par 0.
